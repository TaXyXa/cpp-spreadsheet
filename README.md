Электронная таблица

Ядро электронной таблицы как Excel или Google Sheets. Позволяет:
* Записывать данные в ячейки по их индексам или названию (A1, AX4, ...)
* Вычислять значение ячейки в зависимости от других ячеек через арифметическую формулу.

Если в формуле содержится ошибка (ссылка на текст, деление на 0, циклическая зависимость) 
ячейка будет содержать тип возникшей ошибки
